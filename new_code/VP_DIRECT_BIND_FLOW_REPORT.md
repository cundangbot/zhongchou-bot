# VP 直接发送自动绑定流程修复说明

## 改动范围

- `app/handlers/start.py`
- `app/keyboards.py`

## 新流程

用户在机器人私聊里直接发送 VP 系统单号时，机器人会自动进入核票流程：

1. 检查 VP 是否已经被绑定过。
2. 查询发卡平台付款记录。
3. 校验付款状态是否为已支付。
4. 校验付款记录是否属于当前 Telegram 用户。
5. 如果用户有金额匹配的待付车票，直接完成验票上车。
6. 如果用户没有待付车票，但 VP 有效且金额可匹配项目，则列出可绑定项目按钮。
7. 用户点击项目后，机器人创建对应车票并再次核验 VP，成功后走正常上车流程。

## 文案

已替换为用户指定文案：

- 找到付款记录，需要选择项目
- 订单号已经绑定过
- 订单号账号对不上
- 金额对不上

## 管理端

项目卡片已去掉 `➕ 补已付订单` 按钮，避免管理员误把“直接发 VP”的用户当作手动补单处理。
