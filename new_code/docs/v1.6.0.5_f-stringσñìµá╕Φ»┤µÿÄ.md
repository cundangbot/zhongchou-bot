# v1.6.0.5 f-string 复核说明

本版本再次复核全部 Python 源码，重点检查 Python 3.11 不允许的 f-string 表达式内部反斜杠。

已确认：

- `participated_order_detail` 使用 `default_label`，没有在 `{...}` 内写带换行的字符串字面量；
- `refund_order_detail` 使用 `default_label`，没有在 `{...}` 内写带换行的字符串字面量；
- 全部 Python 文件通过语法编译；
- 全项目扫描未发现 f-string 表达式内部反斜杠；
- 检查脚本说明文字不再包含容易被文本搜索误判的错误示例。

部署后可执行：

```bash
python scripts/check_fstring_compat.py
python -m compileall -q app scripts alembic
```

两条命令都应正常结束，第一条输出：

```text
OK：未发现 f-string 表达式内部反斜杠。
```
