# v1.6.1.4 管理员私聊会话中心

本版把所有“需要来回交流”的客服逻辑统一收口到 `SUPPORT_ADMIN_ID` 的机器人私聊里。

## 业务边界

- 客服咨询：用户在众筹机器人里发消息，机器人转到客服管理员私聊。
- 管理员回复：管理员在自己的机器人私聊里回复用户消息，或者保持某个用户后直接发送。
- 业务审核：退款、报销、提现、资源审核、手动补票仍进入审核群。

## 新增能力

1. 管理员私聊增加“结束这个对话”。
2. 管理员结束会话后，用户收到“您的对话已结束”小卡片，可去热门众筹或回我的众筹。
3. 审核群的退款、报销、提现业务卡片新增“切到用户对话”。
4. 点击切换后，机器人在管理员私聊里建立当前会话；管理员直接发消息即可到达用户。
5. 新增 `support_admin_sessions` 表保存管理员当前会话，减少状态丢失。
