# v1.6.3.8 Alembic overlap repair

## Symptom

`alembic upgrade head` reports:

```text
Requested revision 0003_support_admin_sessions overlaps with other requested revisions 0001_postgresql
```

The database then lacks `crowdfund_projects.discussion_chat_id` and related columns because migration `0004_channel_discussion` was never executed.

## Cause

The server's `alembic_version` table contains more than one row from a migration chain that is now linear, commonly both:

- `0001_postgresql`
- `0003_support_admin_sessions`

## Safe repair

```bash
sudo systemctl stop zhongchou_bot
cd /opt/zhongchou_bot
source venv/bin/activate

python scripts/repair_alembic_overlap.py
python scripts/repair_alembic_overlap.py --apply
alembic upgrade head
alembic current

deactivate
sudo systemctl start zhongchou_bot
sudo journalctl -u zhongchou_bot -n 100 --no-pager
```

The repair script only edits `alembic_version`; it does not delete or alter business data. It aborts when it finds an unknown migration revision.
