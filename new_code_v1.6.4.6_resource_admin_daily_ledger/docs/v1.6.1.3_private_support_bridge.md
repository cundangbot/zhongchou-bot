# v1.6.1.3 内置私聊客服桥

## 这版解决的问题

之前的客服链路经历过审核群工单、外部客服机器人、内置工单中心几种方案，但实际使用上仍然不够顺：

- 用户只想在众筹机器人里直接和小掌柜说话。
- 管理员不想每条消息都点一次工单按钮。
- 客服咨询不应该混进退款、垫付报销、提现、资源审核这些业务审核卡片里。
- 多个用户同时咨询时，管理员需要通过回复某条用户消息来切换当前对话。

所以 v1.6.1.3 改成“本机器人私聊客服桥”。

## 新客服流程

### 用户侧

1. 用户点任意「联系小掌柜」。
2. 用户进入众筹机器人私聊里的客服对话态。
3. 用户直接发送文字、截图、文件、视频或语音。
4. 机器人把消息同步到指定客服管理员的机器人私聊。
5. 用户可以继续补充，不需要一条消息点一次按钮。
6. 用户点「结束联系客服」或发送“结束客服”后，对话关闭。

### 管理员侧

1. 管理员通过 `SUPPORT_ADMIN_ID` 指定。
2. 用户消息会直接出现在这个管理员和众筹机器人的私聊里。
3. 管理员直接回复那条用户消息，机器人会把内容发回对应用户。
4. 管理员点「📌 保持这个对话」后，后续直接发送内容都会发给当前用户。
5. 如果其他用户也发来咨询，管理员回复那位用户对应消息即可切换当前对话。
6. 发送成功后只给管理员一个简短送达回执。

## 业务审核边界

这版只改变“人工咨询”入口。

仍然进入审核群的业务单：

- 退款申请
- 垫付报销
- 满员补票收益提现
- 项目审核
- 资源补交/审核
- 手动补票
- 验票异常风控
- 系统异常告警

不会进入审核群的新内容：

- 用户点「联系小掌柜」后发送的普通咨询消息
- 咨询截图、文件、语音、视频
- 管理员客服回复

## 新配置

```env
SUPPORT_ADMIN_ID=123456789
SUPPORT_PRIVATE_BRIDGE_ENABLED=true
SUPPORT_EXTERNAL_ONLY=false
SUPPORT_DELIVERY_MODE=direct_http
SUPPORT_DELIVERY_FALLBACK_TO_AIOGRAM=true
```

说明：

- `SUPPORT_ADMIN_ID` 是客服管理员 Telegram 数字 ID。
- `SUPPORT_ADMIN_ID=0` 时，系统会使用 `ADMIN_IDS` 里的第一个管理员。
- 管理员必须先打开过众筹机器人，否则机器人无法主动给管理员私聊推送用户消息。
- `SUPPORT_EXTERNAL_ONLY=true` 仍然保留为应急外部客服模式，默认不要开启。

## 数据变化

新增表：

```text
support_bridge_messages
```

用于记录“管理员私聊里哪条消息对应哪个用户会话”，这样管理员回复某条历史消息时，机器人可以准确知道应该发给哪个用户。

新增迁移：

```text
alembic/versions/0002_support_private_bridge.py
```

部署已有数据库时需要执行迁移。
