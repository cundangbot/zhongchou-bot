## 3. 新发现并修复的流程断档

### 3.1 发起众筹输入状态

此前只有部分步骤能取消。现在选择价格、填写博主、上传描述、填写原价、选择购买方式和最终确认阶段都能退出，状态会被清除，不会让下一条普通消息误进入发车流程。

### 3.2 购买渠道资料

平台代购车主进入资料输入后，增加「暂不填写，返回车主项目」。提交后也带回车主项目入口。

### 3.3 资源提交审核后的状态穿透

此前旧上传按钮、命令上传、媒体组延迟消息或管理员资源管理按钮，可能在提交审核后继续写入资源。

现已统一加入数据库状态校验：

```text
上传中：允许编辑
资源已提交 / 审核中：锁定，只能通过或驳回
驳回：重新开放上传
已发布 / 已交付：只读
```

锁定范围包括：

- 发起人上传按钮；
- 管理员上传按钮；
- `/resource_项目编号` 兼容命令；
- 已经打开的旧上传会话；
- 媒体组延迟到达的消息；
- 删除最新资源；
- 清空资源；
- 清空重传。

### 3.4 资源领取分页

每一页发送完成后，无论有没有下一页，都保留「返回资源详情」。资源详情再保留「返回我的资源」，不会在 Telegram 私信资源流里断档。

### 3.5 报销和分润提现

此前 `pending_info` 申请会长期卡住，新点击只能提示“已有申请”，但不能继续也不能取消。

现在：

- 未提交资料的申请可以恢复继续填写；
- 可以取消未提交的申请并删除占位记录；
- 不满足提现条件、等待管理员打款、已完成等页面都有返回车主项目入口；
- 资料提交后返回车主项目。

### 3.6 退款

- 退款资料输入有取消和返回；
- 已提交、已完成提示带回退款详情；
- 管理员确认退款后的用户通知带回退款详情；
- 管理员完成页带回对应项目或管理面板。

### 3.7 管理员搜索

此前进入搜索 FSM 后缺少明确退出按钮，管理员下一条普通消息可能被当成搜索词。

现在搜索输入页带「取消搜索，返回管理面板」，取消后清理状态。

### 3.8 管理员客服回复

此前进入客服回复 FSM 后没有取消按钮。现在增加「取消回复，返回客服工单」，取消时清理当前回复状态。

### 3.9 管理员手动补单

第一个补单输入页面原本的「返回项目详情」只切页面、不清除 FSM。现在按钮改为专用取消回调，会同时清理状态并返回项目详情。

### 3.10 热门众筹

- 私聊项目详情新增「返回热门众筹」；
- 热门列表为空时新增「发起众筹 / 返回我的众筹」。

### 3.11 自动支付选择页

多张匹配待付票和无待付票恢复页均保留「联系小掌柜 / 返回我的众筹」。

## 4. 交互闭环矩阵

| 流程 | 正常完成 | 中途取消/返回 | 异常恢复 |
|---|---|---|---|
| 普通上车支付 | 自动核验成功页 | 返回我的众筹 | 查询状态 / 联系小掌柜 |
| 多票付款 | 选择动态车票后绑定 | 返回我的众筹 | 联系小掌柜 |
| 无待付票付款 | 选择可恢复项目后绑定 | 返回我的众筹 | 无项目时通用保护页 |
| 发起众筹 | 提交管理员审核 | 各输入阶段可取消 | 无效输入保留当前状态 |
| 车主双车位 | 自动核验成功 | 查询状态 / 取消未付票 | 联系小掌柜 |
| 平台代购资料 | 提交管理员 | 返回车主项目 | 无效输入继续填写 |
| 资源上传 | 提交审核 | 取消并返回项目 | 驳回后重新上传 |
| 资源审核 | 发布资源 | 返回项目/管理面板 | 驳回并重传 |
| 资源领取 | 分页领取完成 | 返回资源详情/我的资源 | 发送失败提示联系管理 |
| 退款 | 管理员确认完成 | 取消资料/返回退款票 | 联系小掌柜 |
| 报销/提现 | 管理员确认付款 | 取消资料/返回车主项目 | 恢复未提交申请 |
| 用户客服 | 管理员回复/结束 | 用户结束/返回我的众筹 | 重新打开客服 |
| 管理员客服 | 发送回复/结束工单 | 取消回复返回工单 | `/contact`、`/msg` 主动联系 |
| 管理员搜索 | 查看结果 | 取消返回管理面板 | 再次搜索 |
| 管理员资源管理 | 通过/驳回 | 返回项目/管理面板 | 状态锁阻止旧按钮误触 |

## 6. 无法在当前环境完成的线上验证

当前环境缺少 `aiogram`，启动导入测试停在依赖加载阶段，因此没有真实连接：

- Telegram Bot API；
- Telethon 商家账号；
- faka 查询机器人；
- PostgreSQL；
- 公开频道和审核群。

上线前建议至少跑以下场景：

1. 普通 30 元唯一待付票；
2. 普通 60 元多张待付票；
3. 发起人双车位 60 元；
4. 发起人双车位 120 元；
5. 没有待付票的恢复绑定；
6. 用户屏蔽机器人导致恢复页面发送失败；
7. 资源提交审核后点击旧上传/删除/清空按钮；
8. 管理员驳回后重新上传并再次审核；
9. 退款资料提交、管理员完成和用户查看；
10. 报销/提现资料取消后重新申请。

## 7. 结论

静态代码层面没有发现仍然可进入但无法继续、无法取消或无法返回的主要公开业务页面。外部服务失败均保留用户联系入口或管理员告警；真实 Telegram 权限、faka 格式和 PostgreSQL 并发仍需要部署环境联调确认。
