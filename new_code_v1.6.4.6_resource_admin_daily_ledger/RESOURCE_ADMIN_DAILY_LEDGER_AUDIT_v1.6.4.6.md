# v1.6.4.6 资源审核权限与按日资金账本检查报告

## 1. 资源审核权限边界

### 普通用户/发起人

资源提交审核后，以下入口全部继续锁定：

- 当前上传面板继续发送文字、图片、视频或文件；
- 历史旧上传按钮；
- `/resource_项目编号` 命令；
- Telegram 媒体组延迟到达的后续消息；
- 管理员正在修订资源期间，发起人的旧上传按钮。

用户会收到：

```text
资源已经提交审核，当前不能继续上传、补充或清空。
若审核未通过，小掌柜会重新开放上传入口。
```

### 管理员

项目处于 `resource_submitted` 或 `resource_review` 时，管理员可以使用：

```text
📦 查看/修改资源
➕ 上传/补充资源
🗑 删除最新一条资源
🧹 清空全部资源
🔁 清空并要求发起人重传
✅ 审核通过并发布资源
❌ 驳回并要求重传
⬅️ 返回项目卡片
🏠 返回管理面板
```

管理员追加资源时，项目进入 `admin_uploading`，普通用户仍被锁定；管理员完成后重新回到待审核状态。

资源进入 `resource_published` 或 `delivered` 后，管理员页面改为只读，防止已经开放给用户的资源被静默修改。

## 2. 资金账本按日分页

管理面板点击「💹 资金账本」默认打开北京时间今天：

```text
💹 资金账本
━━━━━━━━━━━━━━
日期：2026-08-02（北京时间｜今天）
收入：+300 元
支出：-60 元
当日净额：240 元
流水：12 条
━━━━━━━━━━━━━━

21:54｜+30 元｜普通车位收入
项目：P.012｜博主：博主A｜用户：1566554813｜说明：车票 T.012 核验成功
```

日期按钮：

```text
⬅️ 前一天
后一天 ➡️
📅 回到今天
🏠 返回管理面板
```

如果单日超过 20 条流水，会增加：

```text
◀️ 本日前页
本日后页 ▶️
```

每天的收入、支出、净额和总流水数量按整日全部记录汇总，不受本日明细分页影响。

## 3. 时间口径

账本按北京时间自然日查询：

```text
北京时间 00:00:00（含）
至下一日 00:00:00（不含）
```

数据库继续保存 UTC naive 时间，本次不需要数据库迁移。
