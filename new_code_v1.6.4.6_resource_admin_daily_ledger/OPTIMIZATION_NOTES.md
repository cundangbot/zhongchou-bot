# 本次整合优化说明

## 已完成

1. 客服消息闭环
   - 用户点击「联系小掌柜」后创建客服工单。
   - 管理群收到工单卡片，可点击「回复用户」。
   - 回复提示改为 Telegram `ForceReply`，管理员需要直接回复机器人提示消息，避免群隐私模式导致消息收不到。
   - 支持文字、图片、视频、文件等媒体回复；发送成功后管理群会出现送达回执；失败会保留工单方便重试。
   - 新增双向客服桥：管理员可直接回复工单卡片/送达回执，或使用 `/reply S.001 内容`、`/sreply S.001 内容` 兜底，全部走统一投递核心。
   - 失败原因会落到 `ContactTicket.last_error`，并在审核群显示可处理原因，例如用户屏蔽机器人、未启动私聊、账号停用、频率限制或代理异常。

2. 满员后频道提醒
   - 项目达到满员并进入满员流程后，系统会额外在公开频道发送一条「拼车成功｜车车已满员」独立面板。
   - 面板文案与项目卡片风格一致，并带「满员后支付30元拿资源」按钮。
   - 使用 `OperationIdempotency` 做幂等保护，每个项目只发送一次，避免重复刷频道。
   - 发送失败会写入 `system_events` 并通知管理群。

3. 管理面板今日化
   - 管理后台统计和列表改为优先展示当天数据。
   - 资金账本显示今日净额和今日流水。
   - 客服、风控、退款、报销提现、异常等列表均增加今日过滤，避免历史数据堆积。

## 建议继续优化

1. 数据时间建议统一为带时区字段，避免 UTC 与本地日期边界不一致。
2. 客服工单可后续升级为同一用户同一项目自动归并到同一会话，而不是每次新建工单。
3. 满员成功面板可增加单独 message_id 字段，方便后续编辑；当前版本为避免迁移风险，使用幂等表记录发送状态。
4. 管理面板可增加「查看历史」按钮，默认只看今天，需要追溯时再进入历史列表。
