# v1.6.0.6 循环导入与启动实测报告

## 修复内容

1. 将 SQLAlchemy `Base` 移到独立的 `app/db/registry.py`。
2. `app/db/base.py` 只负责引擎、会话和数据库初始化。
3. `app/db/models.py` 不再反向导入 `app/db/base.py`，彻底拆除数据库模块循环依赖。
4. 新增 `app/services/project_runtime.py`，承载频道更新、满员提醒、车主进度提醒和资源读取等共享逻辑。
5. 新增 `app/services/payment_flow.py`，承载统一验票后处理逻辑。
6. `app/handlers/start.py` 不再运行时反向导入 `app/handlers/crowdfund.py`。
7. 清理一个无占位符 f-string 和一处未使用调度变量。

## 已执行测试

- 全项目 Python 编译检查；
- 顶层导入依赖图循环检测；
- `import app.main`；
- SQLite 开发模式数据库初始化；
- 18 张 SQLAlchemy 表注册检查；
- 3 个顶层路由注册；
- 7 个 APScheduler 任务构建；
- 模拟完整启动，已运行到 polling 入口并正常退出。
