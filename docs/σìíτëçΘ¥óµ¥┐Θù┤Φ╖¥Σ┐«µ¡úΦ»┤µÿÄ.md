# 卡片面板间距修正说明

本次按最新反馈统一卡片排版：

```text
标题
━━━━━━━━━━━━━━

卡片主体内容

━━━━━━━━━━━━━━
提示/碎碎念/处理建议紧贴显示
```

规则：

1. 标题在卡片外面。
2. 第一条 `━━━━━━━━━━━━━━` 后空一行，再开始正文。
3. 卡片正文结束后空一行，再放第二条 `━━━━━━━━━━━━━━`。
4. 第二条线下面的提示、碎碎念、处理建议不再额外空一行。
5. 已通过 `app/messages/cute.py` 的 `_panel()` 统一控制，后续新增面板优先走 `_panel()`，避免样式再次不统一。
