# v1.6.1.7 客服桥边界与主流程稳定修复

本版按“原有众筹/退款/资源上传流程优先，客服桥只作为显式人工咨询入口”的原则整理。

## 核心修复

1. 只有用户点击 `support:start:*`（联系小掌柜）才进入客服桥。
2. `/start` 会清理旧 FSM 状态，避免用户卡在客服/上传/审核状态。
3. 用户在客服状态发送「🚗 发起众筹」「📋 我的众筹」「🔥 热门众筹」「📦 我的宝贝资源」会自动退出客服并进入对应业务入口。
4. 禁用管理员私聊“任意消息自动发给当前客服用户”的宽泛兜底，避免抢走管理员搜索、手动补票、资源上传等原有流程。
5. 管理员处于客服回复状态但已有资源上传会话时，私聊消息优先进入资源上传。
6. 管理员开始上传平台代购资源时，会清除其保持的客服会话。
7. 私聊上传资源点击完成时，同时识别 `ADMIN_UPLOAD_USER_SESSIONS`，避免提示“当前没有上传会话”。
8. 客服会话按 `SUPPORT_SESSION_TIMEOUT_MINUTES` 自动过期关闭，同一用户优先复用未超时会话。
9. 项目状态统一规范化，兼容历史脏值 `ProjectState.X`，并修复 Python 3.10 无 `StrEnum` 的兼容问题。
10. 后台状态流转异常会弹出明确提示，不再表现为按钮没反应。
11. 管理后台列表支持 `admin:list:type:page` 分页入口。
12. 今日统计按 `BUSINESS_TIMEZONE` 计算本地业务日期。
13. 新增集中日志配置 `LOG_LEVEL`，Docker 增加健康检查、日志轮转和优雅停止。

## 新增配置

```env
SUPPORT_SESSION_TIMEOUT_MINUTES=120
BUSINESS_TIMEZONE=Asia/Shanghai
LOG_LEVEL=INFO
```
