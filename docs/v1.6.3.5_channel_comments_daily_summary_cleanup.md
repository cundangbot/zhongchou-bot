# v1.6.3.5 频道评论区与每日汇总优化

## 已完成

1. 每个新拼车在公开频道只发布一条精简卡片，保留项目编号、博主、车票价格、进度和上车按钮。
2. 完整项目卡片以及发起人提交的文字、图片、视频、动图和文件，自动回复到频道帖子对应的评论线程。
3. 数据库新增讨论组消息映射字段，使后续人数、满员、取消和交付状态变化能够同时更新频道卡片与评论区详情。
4. 每日汇总完整发送成功后，自动删除上一日汇总的全部消息分片；若新汇总只发送了一部分，则删除本次残片并保留旧汇总。
5. 拼车满员时不再额外发送“拼车完成/已满员”公开频道消息，只更新原帖。
6. 若机器人未收到关联讨论组的自动转发，系统会把完整详情暂时保留在频道，并向管理群发送配置告警。

## 上线步骤

```bash
alembic upgrade head
docker compose up -d --build
```

建议配置：

```env
PUBLIC_CHANNEL_ID=-100xxxxxxxxxx
PUBLIC_DISCUSSION_GROUP_ID=0
DISCUSSION_FORWARD_WAIT_SECONDS=8
DAILY_CROWDFUND_SUMMARY_ENABLED=true
```

`PUBLIC_DISCUSSION_GROUP_ID=0` 表示自动识别频道关联讨论组。机器人必须同时加入频道和讨论组，并在讨论组拥有读取消息、发送消息权限。
