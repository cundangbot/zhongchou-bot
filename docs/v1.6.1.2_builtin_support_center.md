# v1.6.1.2 内置客服中心与业务审核边界

本版将用户侧「联系小掌柜」重新收回到众筹机器人内部处理，不再默认跳转 `@jingpinhybot`。

## 逻辑边界

- 人工咨询：用户在众筹机器人内点击「联系小掌柜」，直接发送文字、截图、文件、视频或语音，系统生成 `ContactTicket` 客服小纸条。
- 管理员回复：管理员在众筹机器人待办中心点击「客服小纸条」，或在审核群客服卡片点「回复用户」，即可把回复发回用户。
- 业务审核：退款、垫付报销、提现、资源审核、手动补票、异常验票等仍走原业务流程，并发送到 `ADMIN_GROUP_ID` 审核群，不会混入客服咨询入口。

## 管理员回复方式

1. 待办中心 → 「客服小纸条」 → 「回复用户」。
2. 审核群收到 `💬 新客服小纸条 S.xxx` 后点「回复用户」。
3. 直接回复客服卡片发送 `/reply 内容`。
4. 发送 `/reply S.xxx 内容` 或 `/sreply S.xxx 内容`。

以上入口都会走统一投递核心，并把发送成功/失败回执留在审核群。

## 配置

```env
SUPPORT_EXTERNAL_ONLY=false
SUPPORT_DELIVERY_MODE=direct_http
SUPPORT_DELIVERY_FALLBACK_TO_AIOGRAM=true
```

`SUPPORT_EXTERNAL_ONLY=true` 只作为应急兜底，启用后才会跳转外部客服机器人。
