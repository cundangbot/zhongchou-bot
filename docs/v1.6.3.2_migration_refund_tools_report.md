# v1.6.3.2 更新说明

## 1. 新增跨项目迁移命令

新增管理员命令：

```bash
/migrate_project P.旧项目 P.新项目 原因
```

用于旧拼车未完成时，将旧项目已支付上车车票迁移到新项目。迁移会保留用户 ID、VP 系统单号、支付金额和车票类型，并同步新旧项目人数与资源权限。

安全限制：

- 旧项目和新项目不能相同。
- 已交付旧项目不允许自动迁移。
- 已取消、退款中、已交付等状态的新项目不能作为目标。
- 如果新项目已存在同一用户的 paid 车票，会停止迁移，避免重复加人数。

## 2. 修复退款小票面板过长

管理员面板「退款小票」现在只显示用户已经提交收款资料、等待管理员处理的退款单：

```text
pending_admin
```

不再展示还没提交退款资料的 pending_info 记录，避免列表过长导致 TelegramBadRequest: message is too long。

同时面板最多展示 12 条，并加了全局面板文本截断兜底，避免超过 Telegram 4096 字符限制。

## 3. 新增常用命令工具按钮

管理员面板新增：

```text
🧰 常用命令工具
```

点击后可以按按钮查看常用命令说明，包括：搜索、项目闭环检查、同步项目、迁移旧车用户、绑定待付车票、补已付订单、恢复取消车票、车票改用户、VP 改用户、转移付款车票、回复客服。

这些按钮只展示命令用法，不直接执行危险操作，避免误触。
