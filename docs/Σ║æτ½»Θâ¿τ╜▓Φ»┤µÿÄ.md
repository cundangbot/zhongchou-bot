# 云端部署说明（PostgreSQL）

## Docker 部署

1. 复制配置：

```bash
cp .env.example .env
```

2. 修改 PostgreSQL 密码，并确保 `POSTGRES_PASSWORD` 与 `DATABASE_URL` 中的密码一致。

3. 首次生成 Telethon Session：

```bash
python -m app.tools_login_telethon
```

这一步会生成 `.env` 中 `TELETHON_SESSION` 对应的 `.session` 文件。不要把它发给其他人。

4. 启动：

```bash
docker compose up -d --build
```

5. 查看日志：

```bash
docker compose logs -f tg-crowdfund-bot
```

## 从旧 SQLite 迁移

先备份旧数据库，再执行：

```bash
docker compose up -d postgres
docker compose run --rm tg-crowdfund-bot alembic upgrade head
python scripts/migrate_sqlite_to_postgres.py \
  --sqlite sqlite:///./data/bot.db \
  --postgres postgresql+psycopg://crowdfund:密码@127.0.0.1:5432/crowdfund
```

迁移后核对项目、支付、退款、报销/提现、状态历史和资金账本。

## 生产要求

```env
PAYMENT_TEST_MODE=false
ALLOW_SQLITE_DEV=false
AUTO_CREATE_SCHEMA=false
```

只能运行一个 bot 服务。PostgreSQL advisory lock 会阻止第二个 polling/scheduler 实例启动。
