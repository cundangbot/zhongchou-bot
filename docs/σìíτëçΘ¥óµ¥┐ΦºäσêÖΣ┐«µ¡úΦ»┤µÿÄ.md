# 卡片面板规则修正说明

本次按用户要求统一卡片样式：

```text
标题
━━━━━━━━━━━━━━
主体内容
━━━━━━━━━━━━━━

小掌柜提醒 / 小掌柜碎碎念 / 处理建议 / 下一步提示
```

修正重点：

1. 标题不算卡片内容。
2. 卡片主体必须上下都有 `━━━━━━━━━━━━━━`。
3. 提醒类文案必须放在第二条分隔线外面。
4. 退款、车票、项目详情、客服、搜索、资源、管理待办中心均按同一规则输出。
5. 验票失败、验票服务异常、退款卡住等需要用户继续求助的场景，保留「联系小掌柜」按钮。

本轮没有重写文案风格，只按用户上传的文案体系调整结构和模板落点。
