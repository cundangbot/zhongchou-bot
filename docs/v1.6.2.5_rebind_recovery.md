# v1.6.2.5 订单重新接回与恢复工具

本版新增管理员恢复命令，解决“系统单号已经绑定，但正确用户的我拼车中看不到”的问题。

## 常用排查

```bash
/audit_project P.012
/search VP2026060202331011743
```

## 场景 1：车票已 paid，但挂错 Telegram 用户

```bash
/rebind_user T.012 正确用户ID 原因
```

或只知道 VP：

```bash
/rebind_vp VP2026060202331011743 正确用户ID 原因
```

效果：不重复加车位，只修改 payment_orders.user_id，并把 ResourceAccess 接到正确用户。

## 场景 2：VP 绑定到了错误车票，正确用户有待付车票

```bash
/move_bind T.目标待付车票 T.当前占用车票 原因
```

效果：把外部付款凭证从源 paid 车票转到目标 pending 车票，项目进度自动回滚/重新应用。

## 场景 3：正确用户没有待付车票，但需要补一张已支付车票

```bash
/add_order P.012 用户ID VP系统单号
```

前提：VP 没有被其它车票占用。若已占用，请先用 /rebind_user 或 /move_bind。
