# v1.6.0.2 管理员手动补票按钮

本版本仅增加审核群管理员项目详情中的“🎫 手动补票”入口，不增加作废补票或误绑定回滚功能。

## 操作流程

1. 在审核群打开某个项目详情。
2. 点击“🎫 手动补票”。
3. 从该项目的待支付车票中选择一张。
4. 发送 VP 开头的发卡平台系统单号。
5. 系统复用原有管理员手动补单服务，完成绑定、项目进度更新、车主提醒和满员触发。

## 限制

- 只显示状态为 `pending` 的待支付车票。
- 已支付、已取消、已退款或已过期车票不能补票。
- 系统单号必须为 VP 开头并符合格式。
- 已被其他车票使用的系统单号不能重复绑定。
- 本版本不提供“作废补票”“撤销验票”“更正已绑定单号”。
