# v1.6.1.5 客服边界、资源预览与管理后台优化说明

## 本次核心目标

本次修改以 `new_code.zip` 为基准，重点处理“客服桥吞掉发起众筹、退款、资源上传资料”的问题，并补齐几个高风险流程增强。

## 已完成修改

1. **客服桥入口收窄**
   - 只有 `support:start:*`，也就是「联系小掌柜」按钮会进入 `ContactSupport.message`。
   - `/start`、我的众筹、热门众筹、发起众筹等业务入口会先清理旧 FSM 状态。
   - 用户在客服状态里发送「🚗 发起众筹」「📋 我的众筹」「🔥 热门众筹」会自动退出客服桥并进入对应业务。

2. **客服会话自动归并与超时**
   - 同一用户已有未关闭客服单时，会自动复用原会话，不再一条消息一张新工单。
   - `SUPPORT_SESSION_TIMEOUT_MINUTES` 控制客服会话超时时间，默认 120 分钟。
   - 超时会话会自动关闭，管理员保持会话也会自动解除。

3. **管理员客服与资源上传隔离**
   - 管理员进入上传资源流程时，会清掉保持的客服会话。
   - 管理员私聊上传资源优先级高于客服回复状态，资源不会被发给正在客服的用户。
   - 管理员“保持客服对话”的兜底 handler 仅在无 FSM 状态时触发，避免吞掉退款、搜索、上传等业务状态。

4. **资源上传预览确认**
   - 发起人上传资源后，点击完成会先看到分类/数量/样例预览，再确认提交审核。
   - 管理员上传平台代购资源后，点击完成会先预览，再确认私发给已支付用户。
   - 管理员私聊上传会话和审核群上传会话都会被识别，修复私聊上传后完成按钮找不到会话的问题。

5. **管理后台分页**
   - 管理后台列表 callback_data 统一为 `admin:list:<type>:<page>`。
   - 待审核、待补资源、报销/提现、退款、客服、风控列表支持分页。

6. **本地业务日期统一**
   - 新增 `BUSINESS_TIMEZONE`，默认 `Asia/Shanghai`。
   - 管理后台“今日”统计和时间展示统一按本地业务日期计算。

7. **集中化日志与 Docker 增强**
   - 新增 `app/services/logging_setup.py`，支持 `LOG_LEVEL` / `LOG_FORMAT`。
   - Dockerfile 增加编译级 healthcheck。
   - docker-compose 增加日志轮转和 bot 优雅停止时间。

8. **callback_data 初步集中管理**
   - 新增 `app/callbacks.py`，先集中管理客服入口、资源确认、管理后台分页等高风险 callback。
   - 历史 callback 字符串仍保留兼容，后续新增按钮建议统一从 `app.callbacks` 生成。

## 建议上线验证路径

1. 普通用户 `/start` 后点「联系小掌柜」，发送文字/图片，管理员私聊应收到。
2. 同一个用户再次点「联系小掌柜」，应复用原客服单。
3. 用户在客服状态发送「🚗 发起众筹」，应退出客服并进入众筹资料填写。
4. 发起众筹描述资料、退款资料、资源资料均不得出现在客服桥。
5. 管理员点上传资源后，在私聊发送资源，客服桥不得把资源发给用户。
6. 上传完成后必须先出现预览确认，再提交审核/私发。
7. 管理后台各列表能翻页，旧第一页按钮仍兼容。
