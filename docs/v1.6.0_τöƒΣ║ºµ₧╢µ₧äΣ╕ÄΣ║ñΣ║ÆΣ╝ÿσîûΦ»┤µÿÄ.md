# v1.6.0 生产架构与交互优化说明

## 本次范围

本版只围绕以下范围升级：状态机、资金账本、幂等、PostgreSQL、单实例、订单页面返回路径、验票状态刷新、客服上下文、热门排序、空页面引导、资源领取进度、管理员搜索、异常面板、健康检查和命令菜单精简。

## 核心表

- `project_state_history`：项目状态变化历史
- `financial_ledger`：统一资金流水
- `operation_idempotency`：关键操作幂等键
- `resource_claim_progress`：用户资源领取进度
- `system_events`：运营异常记录
- `system_metrics`：系统运行指标

## 管理入口

机器人启动后会在审核群创建或更新一条固定「管理操作中心」消息。所有日常管理从该面板进入，不占用 Telegram 命令菜单。

## 数据迁移

首次部署 PostgreSQL：

1. `alembic upgrade head`
2. 执行 `scripts/migrate_sqlite_to_postgres.py`
3. 核对项目、订单、退款、提现、账本和状态历史
4. 启动正式 bot

## 重要限制

- 正式环境必须 PostgreSQL。
- 只能运行一个 bot 实例；数据库 advisory lock 会拒绝第二个实例。
- 不要同时启动旧 SQLite 版和 PostgreSQL 版处理同一个 Bot Token。
