# v1.6.0.4 客服工单回复回执

## 调整内容

1. 管理员点击“回复用户”并发送内容后，只有 Telegram Bot API 成功接受用户私聊消息，工单才更新为 `answered`。
2. 审核群会收到明确回执，包括工单编号、用户、回复管理员和发送时间。
3. 从单独的新工单卡片进入回复时，原工单卡片会同步显示“已回复用户”，按钮变为“继续回复用户 / 关闭工单”。
4. 回复失败时，工单仍保持待回复状态，并显示失败原因和重试按钮。
5. 媒体回复如果附件发送失败，会尽量撤回已经发出的提示头，避免用户只收到半条回复。

## 注意

“已成功发送”表示 Telegram Bot API 已接受并投递到用户私聊，不代表用户已经阅读。
